# Reversible Windows alpha installer

Original implementation contributor: OpenAI Codex (AI assistant). Project owner/creator/maintainer: arsenal-pt. Eligible original code is GPL-3.0-only; preserve the repository's LICENSE and LICENSE-SCOPE.md. The installer contains no game assets, upstream framework, executable, DLL, save or archive patch.

Install Python 3.10 or later for Windows, then separately install compatible Infinite Heaven and IHHook using their own instructions. The Microsoft Visual C++ x64 runtime required by IHHook is also an upstream prerequisite. Extract the complete core ZIP before using it. `Install.cmd` opens a picker for your existing `MGS_TPP` directory if no command arguments are supplied. It prints the alpha scope, verifies package hashes and dependencies, then installs; invocation is the authorization, so there is no second confirmation dialog.

The alpha supports the owned menu and regular-soldier logical simulation/diagnostics in its declared source scope. Missing resource-dependent routines deliberately remain unavailable. Native package, gameplay, foreground-performance and endurance acceptance are pending. This installer does not enable disabled resource proof flags. The optional companion, SDK, IH-extra actor adoption and experimental platform packages are not installed by it.

```powershell
python -B installer/install.py check --game-dir "D:/Games/MGS_TPP"
python -B installer/install.py install --game-dir "D:/Games/MGS_TPP"
python -B installer/install.py uninstall --game-dir "D:/Games/MGS_TPP"
python -B installer/install.py restore --game-dir "D:/Games/MGS_TPP" --receipt "D:/Games/MGS_TPP/mod/imb-install-backups/<version>/<id>/install-receipt.json"
```

`Uninstall.cmd` removes only an active recorded installation. A normal uninstall restores the first pre-install versions of overwritten owned filenames, removes owned files that were absent before the first install, and keeps private life data/recordings and all backup receipts. A repeat install or version upgrade keeps that earliest provenance and records the previous active receipt. Older receipts are history, not a way to overwrite newer installations. Files edited since installation are preserved and cause a refusal before any removal. Copy your edits elsewhere and compare the receipt hashes before choosing how to resolve that refusal; there is no destructive force option.

`restore --receipt` uninstalls an active completed install, or rolls an interrupted install/restore back to its prior consistent state. Corrupted backups, unrecognized changed files, a running MGSV process, links/junctions or an unrelated newer active install cause a refusal. Do not move/delete backup receipts while the mod is installed. Paths are game-root specific; moving the game folder requires reviewing/remapping backups manually rather than silently trusting an old receipt.

The only native targets are the 20 owned Lua filenames under `mod/modules` and `mod/nlab`, explicitly enumerated in `OWNED_TARGETS`. The manifest must map each to `core/GameDir/<target>` with exact size and SHA-256, match root `VERSION`, and declare `nativeAcceptance: false`. It never writes executable files, game archives, external IH/IHHook modules/settings, geometry or game saves. Auxiliary receipts and backups reside only in `mod/imb-install-backups/<version>/<unique-id>`. An OS transaction lock prevents two installers from modifying the same game at once and releases on process exit/crash; its one-byte file remains in the backup folder. Atomic file replacement, preflight backups, a persistent journal and hash-guarded rollback handle partial failures. Cross-file transactions cannot be fully atomic across sudden hardware failure; recovery uses the journal and preserves unknown newer edits.

The prerequisite detector checks a Windows PE named `mgsvtpp.exe`, nonempty IH `InfMenu.lua` and `InfMenuDefs.lua`, and an identified PE IHHook in `dinput8.dll`, `IHHook.dll/.asi`, or `plugins/IHHook.dll/.asi`. It does not download or run these files. PE/name/string checks do not certify a legally acquired copy, framework health, executable revision or the VC++ runtime. Use a legitimate MGSV TPP installation and upstream supported versions; do not use this installer to create or bypass a game installation.

The public alpha excludes the separate private IH staff-adoption experiment. If the exact legacy `mod/modules/NpcIHStaff.lua` provider is present, both `check` and `install` refuse before writing anything. Use a separate clean test game/mod setup or manually review backups before migrating that private adapter. The installer never deletes/disables it, and does not reject or modify original IH NPC modules or unused `nlab` helper files. Restoration of a recorded installation remains available if that private adapter was added later.

The release builder generates `installer/package-manifest.json` from the final payload. Optional `sourceTag`, `sourceCommit` (nullable until publication), and `sourceTreeSha256` identify the matching source; the final tag/commit and ZIP digest belong in the published release receipt. The installer reads the version from the manifest and checks root `VERSION`, so its script is not renamed for every release. Package hashes detect corruption, not a malicious publisher; obtain releases from the official repository.

Upstream references: [Infinite Heaven installation](https://mgsvmoddingwiki.github.io/Infinite_Heaven/), [Infinite Heaven](https://www.nexusmods.com/metalgearsolidvtpp/mods/45), [IHHook](https://www.nexusmods.com/metalgearsolidvtpp/mods/1226), [IHHook proxy/dependency source at TinManTex revision 71801f1c](https://github.com/TinManTex/IHHook/blob/71801f1cb861a1e1ebad051be222e34a5355b4fc/README.md). Later forks/revisions have different executable-version requirements; follow the matched upstream release. The local read-only structural check is distinguished from these documented requirements.

Developers run `python -B tests/test_installer.py` for temporary fake-game filesystem transaction tests. These do not launch MGSV or prove gameplay/native performance. Never replace the fake fixture directory with a real game root.
