## Quality and source scope

425 parent references and 434 rendered views. Original seating families retain their native LOD comparison pages. Other native levels are inventoried separately from rendered coverage. Model components are not asserted to be complete assembled or interactive objects.

Exact native paths, captured container/texture chains, texture pixels/mips, hashes, provenance, Library IDs and naming evidence are in detail/technical views. Source namespaces include MGO references found in as-installed archives; vanilla-install status, exhaustive alternatives and effective runtime priority remain unresolved. Original retained-only records do not claim a current DAT check.

Actual base textures/UVs use approximate studio shading. Normal/specular/packed FOX shaders and game collisions/interactions are not reproduced. Turntables are camera orbits around static models, not native animations.

Konami retains rights in game artwork; only reference previews/metadata are included. Project owner: arsenal-pt. Authored preparation uses OpenAI Codex (AI/LLM). Community tool attribution remains in [central credits](sources-and-credits.md). No raw models, textures, archives, decoded geometry or Blender scenes are distributed.
