# Native inspection and activity evidence

## Camera-only inspection

When inspecting a hard-to-see base area, keep Snake as the streaming anchor. Use the game's native camera controls/presets and a read-only bridge to inspect geometry. Record the full camera/pad baseline to a file before changing state, and restore it in a finally cleanup path. A camera acknowledgement is not evidence that the full original preset was restored.

Capture baseline player coordinates and sample them through the session. A player-drift guard should abort if the player moves beyond a small defined tolerance. Avoid input injection, warp commands or movement commands for ordinary visual inspection. At completion, verify controls/pad guard restored, clock resumed, queues released, camera settings restored, process state known and streaming still with Snake. One successful cleanup showed drift of about 0.00004 m; this is evidence for that capture only.

Use multiple angles and distinguish a source-site still from a frame during an active event. Tie screenshots to a monotonic timestamp and the corresponding one-second feed/clip interval. If an event trace says muster, the image should show the same interval and population. Do not use the failed in-game action recorder as a substitute for independent live-feed evidence.

## Native paired CQC

The private paired-training prototype used fixed partners and stations, with one assembly move per participant, alternating throw/receive roles, bounded recovery phases and explicit lease cleanup. Six existing soldiers completed about 304.7 real seconds, 27 rounds and 13 cycles with fixed assignments. A later four-person showcase run completed in 305.07 raw real seconds, 27 rounds and 13 cycles, with four assembly moves and cleanup complete.

These demonstrations used later private development versions, not public alpha. The four-person final recording temporarily held the in-game clock at noon after a clock rebase so lighting and scheduled events would not drift; the CQC raw-real timer and NPC movement continued. It proves completion under held-lighting recording conditions only. An earlier 283.149-second run stopped for an urgent need, and another attempt was rejected because scheduled evening muster had priority. Do not claim normal-clock five-minute endurance, automatic scheduling, broad camera/rumble acceptance or public-build proof.

The native animation workflow separates these claims: action request accepted, state transition observed, completion event observed and complete session with cleanup. Stored pose height does not prove a physical fall. Player reference animation inspection is separate from NPC actor capability. An experimental zero-root animation clone produced floating/misaligned poses; restoring source root curves improved posing. Do not ship neutralized roots based on offline structure alone.

## Showcase provenance

Later private footage captured muster, gathering, paired motion and a standing/doorway queue at the shower location. It did not show NPC shower entry or fixture use. Footage was from installed development NpcLife 0.1.21, IH provider 0.2.6, CQC 0.2.3 and Command1 v9.1, not the published alpha. It is a bounded showcase record, not a release acceptance test.
