## Current contribution-ready gates

- Add route/service definitions only with exact platform grade, source route and native arrival/dwell proof.
- Add actor actions only with family-specific capability evidence, identity-generation safety and tested release to original control.
- Add new platform geometry only after per-platform source inventory, frame transforms, archive references and separate render/physics/navigation checks.
- Add animation claims only when request, actor-family support, event, pose/support, recovery and cleanup evidence are each present.
- Add performance claims only from comparable same-scene interval captures that reproduce the trigger or explicitly mark it unresolved.
- Keep all development findings labeled separately from the published alpha until the exact public source and dependencies receive fresh native acceptance.
