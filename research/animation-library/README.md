# MGSV Animation Reference Library

[**Open Library →**](https://mgsv-animation-reference.arsenal-pt.chatgpt.site/)

Search **1,312 published animations**, including every original metadata field, in one table. See names and exact filenames, filter recorded sources and categories, sort, and open a still or GIF when needed. **Details** keeps the complete original metadata in the same row. No images load automatically.

These are **offline references**. Preview speed is chosen; native timing, arbitrary character compatibility and whole-game coverage are unverified. Source-derived labels may await per-clip visual review. Character and moveset remain **Unknown** where direct evidence is absent; the Ocelot preview mesh does not establish motion origin.
