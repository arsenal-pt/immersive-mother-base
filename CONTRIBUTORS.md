# Project roles and contribution credit

| Role | Credit |
| --- | --- |
| Repository owner, project creator and maintainer | **arsenal-pt** — concept, requirements, direction, testing, official merges and releases |
| Original implementation contributor/tool | **OpenAI Codex (AI assistant)** — original project code, companion tooling, build helpers and documentation produced through AI/LLMs under arsenal-pt's direction |
| Upstream work | The authors linked in [CREDITS.md](CREDITS.md) — game resources, frameworks, tools and libraries; their work is not claimed as ours |
| Future contributors | People who submit code, models/recipes, documentation, tests, issue investigations and other accepted contributions; credit their actual work individually |

The implementation to date was developed entirely using AI/LLMs. This does not imply an independent OpenAI maintainer, OpenAI endorsement, a Codex GitHub account, or human authorship of AI-written code. Exact model/session choices varied during development. Arsenal-pt remains the owner and person directing the official project.

## Commit attribution

GitHub's Contributors display is derived from commit authors and account-linked email addresses, not this role table. Publishing through an authenticated connector can record that account as the committer/author even when an AI assistant produced the implementation. This documentation records the actual development method. Existing human README and repository-creation commits are retained; we do not rewrite them to hide valid contributions.

Human-authored work should use the contributor's own Git identity. Code is one way to contribute; documentation, testing and fixes count too. Agent-generated local commits may use the clearly labelled, unlinked identity `Codex <codex@local.invalid>`; that is a local provenance label, not a claim to any real person's account. Connector-created commits include an explicit implementation attribution in their message when the assistant did the work.

See GitHub's [contributor documentation](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-a-projects-contributors). Contributions are welcomed through the official repository; eligible original submissions use GPL-3.0-only and contributors keep their applicable rights.
